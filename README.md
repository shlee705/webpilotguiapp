# WebPilot Desktop 0.4.5

이 저장소는 **0.4.5** 프로젝트입니다. 전체 소스, 개발 설정, 테스트, 앱 아이콘, 원본 `testReport/report.pdf`와 `release/0.4.5/win-unpacked` 실행 폴더 전체를 포함합니다. 기존에 업로드한 버전도 보존되어 있습니다. 실행파일과 런타임은 Git LFS로 관리합니다. 전체 프로젝트 ZIP은 [v0.4.5 릴리스](https://github.com/shlee705/webpilotguiapp/releases/tag/v0.4.5)에서도 받을 수 있습니다. 실행기록, 개인 설정과 재설치 가능한 개발 의존성(프로젝트 루트의 `node_modules`)은 제외했습니다.

Git으로 받을 때는 Git LFS가 설치된 환경에서 저장소를 복제한 뒤 `git lfs pull`을 실행하세요. GitHub의 일반 **Download ZIP** 대신 위 릴리스의 `WebPilot-0.4.5-full-project.zip`을 받으면 실행에 필요한 실제 파일 전체가 포함됩니다.

소스만 받은 경우 `npm ci` 후 `npm run desktop`으로 실행하거나 `npm run package`로 Windows 실행파일을 만들 수 있습니다.

별도 웹테스트 백엔드의 작업을 사용자가 체감하도록, GPT-6 Luna가 전용 Edge에서 실제로 사이트를 조작하는 Windows GUI입니다. 화면에는 **웹사이트 버그 탐색중...**으로 표시하며, 시각적 조작과 백엔드의 검사·버그 판정은 분리되어 있습니다.

## 시작

1. `release/0.4.5/win-unpacked/WebPilot.exe`를 실행합니다.
2. 왼쪽 아래 **QA팀** 계정을 눌러 OpenAI API 키와 모델을 저장합니다. 기본 모델은 GPT-6 Luna입니다.
3. URL과 원하는 버그 탐색 내용을 보냅니다.
4. 대화에 표시된 **테스트 설정** 카드에서 URL·모델·탐색 횟수를 확인합니다. **설정 바꾸기**에서 수정할 수 있습니다.
5. **시작하기**를 누르면 최대화된 전용 Edge에서 실제 이동·입력이 시작됩니다. 시작 전에는 API 호출이나 브라우저 실행을 하지 않습니다.

키 발급: [OpenAI API keys](https://platform.openai.com/api-keys). 연결 확인은 모델 목록 조회이며 응답 생성은 하지 않습니다. 사용량은 QA팀 설정 안에서 이 앱이 집계한 API 토큰으로 확인할 수 있습니다.

## 화면과 모션

참고 영상에 맞춰 흰 본문·회색 사이드바·검은 막대 로고의 WebTestPilot 화면으로 구성했습니다. 중앙 입력창은 첫 메시지를 보내면 대화 하단으로 이동하고, 새 설정 카드의 행이 차례로 나타납니다. 시작 버튼을 누른 확인은 말풍선으로 기록됩니다. 실제 모델 요청에는 설정 카드의 URL과 요청 내용이 그대로 전달됩니다.

왼쪽 **검사 기록**은 모든 대화를, **보고서**는 보고서가 첨부되었거나 첨부 대기 중인 대화를 표시합니다. 새 메시지의 등장 모션은 한 번만 재생되며, 기록을 다시 열거나 앱을 새로고침하면 정적으로 표시됩니다. 운영체제의 모션 감소 설정도 지원합니다. 활동 효과는 실제 실행 상태에 연결되어 완료·오류·중지 시 멈춥니다.

## 로그인 계정

버그 탐색 설정의 **로그인 계정 사용**을 켜서 입력하거나 프롬프트에 다음처럼 추가합니다.

```text
https://example.com 메뉴를 둘러봐 줘.
아이디: 테스트용 아이디
비밀번호: 테스트용 비밀번호
```

계정 줄은 메시지·기록에서 제거됩니다. 계정 값은 이번 작업의 메모리에만 보관하고, 모델에 전달하지 않습니다. 완료·중단·대화 삭제 시 일회성 계정을 해제합니다. 대상 사이트의 출처를 바꾸거나 앱을 다시 열면 계정을 다시 입력해야 합니다. 화면을 새로고침해도 실행 중인 작업과 효과를 취소합니다.

로그인 요청도 다른 자연어 지시사항과 함께 우선 탐색 대상으로 전달합니다. 계정을 지정하지 않아도 로그인 진입 버튼을 눌러 화면과 입력란을 확인할 수 있습니다. 계정 입력·제출은 사용자가 이번 작업에 지정한 계정이 있을 때만 진행하며, 페이지에 표시된 예시 계정을 대신 사용하지 않습니다.

자동 로그인은 같은 출처의 명확한 HTML POST 폼과 일부 SPA 로그인 폼을 지원합니다. SPA는 같은 출처의 인증 경로에 정확한 계정쌍을 담은 JSON 또는 form 요청을 한 번만 허용합니다. 서버 요청 없이 처리되는 폼은 허용된 제출 이벤트와 실제 화면 전환을 함께 확인하며, 서버 인증 성공으로 표시하지 않습니다. 외부 SSO, 인증 리디렉션, CAPTCHA와 추가 인증은 자동으로 진행하지 않습니다. 로그인 제출과 로그인 성공은 구분하며, 성공했다고 임의로 표시하지 않습니다.

## 지시사항과 글쓰기 입력

프롬프트에 메뉴·검색·로그인·글쓰기처럼 여러 대상을 적거나 순서·입력 내용을 지정할 수 있습니다. 모델은 원래 요청과 현재 페이지의 조작 가능한 요소, 최근 동작 결과를 함께 보고 다음 동작을 선택합니다. 지시한 대상을 먼저 확인하고 남은 횟수는 다른 안전한 요소를 탐색합니다.

검색창과 글쓰기 화면의 제목·여러 줄 본문·편집기에 일반 텍스트를 입력할 수 있습니다. 입력 한 번에 4,000자까지 지원하고 계정 필드에는 전용 로그인 절차만 사용합니다. 공지·게시글 작성 흐름에서는 별도 등록 지시가 없어도 모델이 필수 입력과 등록 버튼 제출까지 판단합니다. 내용을 지정하지 않은 작성 점검에서는 테스트 글임을 알 수 있는 제목·본문을 사용합니다. 요청에 **초안만 작성**, **제출하지 마**, **읽기 전용** 같은 제한을 적으면 제출하지 않습니다.

글 등록은 같은 출처의 검증된 작성 폼과 글 생성 요청으로 제한합니다. 등록 버튼을 실제 클릭한 뒤 응답과 후속 화면을 읽어 **등록 확인**, **서버 거절**, **화면에서 확인하지 못함**을 구분합니다. 이미 보낸 등록 요청을 자동 반복하지 않으며, 전송 여부가 불확실하면 중단합니다. 이 결과는 해당 조작의 관측 기록이며 별도 백엔드의 버그 판정이 아닙니다.

## 웹사이트 버그 탐색 화면

- 현재 페이지의 URL·제목·본문·조작 가능한 요소 목록을 모델에 전달합니다. 모델은 이 목록의 일회성 요소 ID만 선택할 수 있습니다.
- 모델이 선택한 요소에 포인터가 움직이고 실제 클릭·입력·스크롤 이벤트가 발생합니다. 화면 크기가 바뀌거나 요소가 사라지면 현재 상태를 다시 확인합니다.
- 새 작업에서는 스크린샷을 생성·저장·전송하지 않고 셔터 효과도 표시하지 않습니다. 이전 버전에서 저장한 캡처는 기존 대화에서 열 수 있습니다.
- 사이트 안에서는 검정 포인터의 이동·클릭만 표시합니다. 전역 배너·전체 화면 테두리·포인터 이름표는 표시하지 않습니다. 앱에서는 페이지 읽기 → 동작 선택 → 실제 조작이 움직이는 카드로 표시됩니다.
- 새 작업의 기본 탐색 횟수는 10회이며 설정에서 1 이상의 정수를 직접 입력할 수 있습니다. 기존 계획이나 직접 지정한 횟수는 바꾸지 않습니다. 지시한 대상을 먼저 확인했더라도 실제 실행한 클릭·입력·스크롤·로그인·글 제출이 설정 횟수에 도달할 때까지 탐색합니다. 차단된 선택과 실행하지 못한 오류는 집계하지 않으며, 안전한 진행이 불가능하면 미완료 오류로 중단합니다. 마지막 동작이 제출이면 후속 화면을 읽어 결과를 확인한 뒤 종료합니다. 등록 요청을 보냈다는 사실과 서버에서 등록이 확인됐다는 사실은 구분합니다.
- 모든 조작 전에 전용 Edge를 앞으로 가져옵니다. 완료·취소 시 해당 탐색 창과 효과를 종료합니다. **Esc** 또는 **응답 중지** 버튼으로 중지합니다.

## Computer Use 반응 속도

전용 Edge의 전경 제어는 세션마다 한 번 준비해 재사용합니다. 동작 직전의 전경 확인과 같은 출처·요소 재검증은 유지하면서 중복 호출과 고정 대기를 줄였습니다. 검정 포인터의 이동은 약 140ms이며, 짧은 입력은 실제 키 이벤트로 진행합니다. 200자가 넘는 본문은 네이티브 텍스트 입력을 작은 묶음으로 전송하고 묶음마다 필드와 포커스를 다시 확인합니다. 클릭·입력 뒤에는 페이지의 DOM·요청·로딩 표시를 짧게 확인하므로 준비된 페이지는 바로 다음 단계로 넘어갑니다.

GPT-6 Luna의 단일 동작 선택은 공식 지원되는 `low` 추론 강도를 사용합니다. 모델에 보내는 현재 페이지 문맥과 최근 동작 기록도 압축합니다. 다른 모델의 추론 설정은 변경하지 않으며, 실제 API 응답 시간과 사이트 로딩 시간은 네트워크와 서비스 상태에 따라 달라집니다.

## 범위와 보관

시작 URL과 프로토콜·호스트·포트가 모두 같은 origin 안에서만 이동합니다. 개인 Edge 프로필과 분리된 세션을 사용하며, 임의 코드·전역 마우스·전체 OS 제어를 모델에 제공하지 않습니다. 지정 계정의 로그인과 검증된 공지·게시글 생성 폼은 제출할 수 있습니다. 외부 이동·새 창·다운로드·결제·삭제·계정 변경과 그 외 상태 변경 요청은 계속 차단합니다.

DOM은 신뢰하지 않는 페이지 자료로 취급하고 명령으로 실행하지 않습니다. 입력 필드 값과 지정된 로그인 비밀은 모델 문맥·공개 출력에서 제외합니다. OpenAI API 키는 메인 프로세스에서 Windows safeStorage로 암호화해 저장하며 대화에 넣지 않습니다.

백엔드의 실제 검사와 이 시각적 작업은 별개입니다. 이 GUI는 백엔드 결과나 진행률을 추정하지 않습니다. 별도 백엔드 API 계약이 없는 상태에서 호출·연동 완료를 표시하지 않습니다.

## 오류 복구와 보고서

모델의 일시적 연결 오류·응답 누락 등은 대기 후 제한적으로 재시도하고 현재 단계를 화면에 알립니다. 이미 실행한 클릭·입력·로그인은 자동 재실행하지 않습니다. 복구하지 못한 오류와 사용자 중지는 설정 카드의 **다시 시도**로 새 작업을 시작할 수 있습니다. 로그인 계정은 다시 입력합니다.

작업이 끝나면 프로젝트 루트의 `testReport/report.pdf`를 읽어 채팅에 파일 카드로 첨부하고 **버그 탐색을 완료했고 보고서를 완성했어요.**를 표시합니다. 이 파일은 미리 준비된 보고서 또는 별도 백엔드가 작성한 보고서이며, 앱에서 보고서 내용을 생성하거나 수정하지 않습니다. **보고서 열기**를 누르면 앱 안의 PDF 뷰어가 열립니다. 이전·다음 페이지, 페이지 번호 직접 입력, 확대·축소·페이지 맞춤을 지원하며 닫기 또는 Esc로 대화로 돌아갑니다.

PDF 뷰어는 첨부된 보고서의 ID만 받아 메인 프로세스가 읽은 PDF를 표시합니다. [PDF.js](https://mozilla.github.io/pdf.js/examples/)와 글꼴·문자 매핑·디코더를 함께 배포하므로 외부 PDF 앱이나 인터넷 연결 없이 볼 수 있습니다. 읽기·표시 오류에는 다시 시도를 제공하며, 사본이 없거나 손상된 경우 **보고서 다시 불러오기**로 원본을 다시 첨부할 수 있습니다. 보고서 내용의 스크립트·외부 링크·폼은 실행하지 않습니다.

첨부 시 보고서 사본을 앱 데이터에 보관하므로 원본이 갱신되어도 이전 대화의 파일은 유지됩니다. 파일이 없거나 읽기 실패 시 완료 보고서 문구를 표시하지 않고 **다시 불러오기**를 제공합니다. 배포 실행 파일은 `webpilotWorkspace` 표식이 있는 프로젝트 루트에서 보고서를 찾으며, 프로젝트 밖으로 옮겨 사용하면 실행 파일 옆의 `testReport/report.pdf`를 사용합니다.

## 개발과 검증

```powershell
npm install
npm run desktop
npm test
npm run test:ui
npm run build
node scripts/smoke-site-dom.cjs
node scripts/smoke-site-buttons.cjs
node scripts/smoke-site-inputs.cjs
node scripts/smoke-site-publish.cjs
node scripts/smoke-tour-desktop.cjs
npm run package
```

브라우저 UI 테스트는 전용 5197 포트를 사용합니다. 실제 Edge 검증은 로컬 사이트와 임시 프로필을 사용하며, 모델 응답은 모의 응답으로 확인합니다. 유료 API 호출은 사용자가 키를 설정하고 작업을 시작한 뒤 수행됩니다. 배포에는 `release/0.4.5/win-unpacked` 폴더 전체가 필요합니다.

모델 목록: [OpenAI 공식 모델 문서](https://developers.openai.com/api/docs/models). 기존 모델 선택과 직접 ID 입력을 지원합니다.
